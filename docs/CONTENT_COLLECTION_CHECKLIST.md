# Checklist de recopilación de contenido

Esta lista reúne las decisiones y materiales que Contax debe entregar o confirmar antes de publicar el refactor.

## 1. Identidad y contacto

- [ ] Logo horizontal para fondo claro.
- [ ] Logo horizontal para fondo oscuro o versión monocromática.
- [ ] Isotipo en SVG o PNG transparente de alta resolución.
- [ ] Teléfono oficial.
- [ ] Número de WhatsApp y mensaje inicial sugerido.
- [ ] Email oficial.
- [ ] Dominio oficial.
- [ ] Instagram, Facebook y LinkedIn oficiales.
- [ ] Enlace de agenda, si se utilizará.
- [ ] Horarios y zonas horarias de atención.
- [ ] Direcciones que pueden publicarse.

## 2. Estados Unidos y Colombia

Para cada país:

- [ ] Nombre legal de la entidad que presta el servicio.
- [ ] Ciudad/estado o ciudad/departamento de operación.
- [ ] Servicios disponibles.
- [ ] Servicios no disponibles o con restricciones.
- [ ] Credenciales, registros o licencias publicables.
- [ ] Monedas y métodos de pago aceptados.
- [ ] Canal de contacto responsable.
- [ ] Avisos legales o tributarios requeridos.

## 3. Servicios

- [ ] Contabilidad / Bookkeeping.
- [ ] Impuestos personales.
- [ ] Impuestos empresariales.
- [ ] Creación de empresas.
- [ ] Nómina / Payroll.
- [ ] Asesoría contable y financiera.
- [ ] ITIN.
- [ ] Servicios para clientes internacionales.
- [ ] Resumen comercial de cada servicio.
- [ ] Tres entregables o beneficios por servicio.
- [ ] Países donde aplica cada servicio.
- [ ] CTA apropiado para cada servicio.

## 4. Planeación tributaria

- [ ] Definición aprobada de planeación tributaria.
- [ ] Diferencia aprobada frente a preparación de impuestos.
- [ ] Beneficios que se pueden comunicar sin prometer resultados.
- [ ] Casos o situaciones frecuentes por país.
- [ ] CTA para solicitar revisión tributaria.
- [ ] Aviso educativo/legal revisado.

## 5. Tips y recursos

Preparar inicialmente entre seis y doce recursos:

- [ ] Título y resumen.
- [ ] Categoría.
- [ ] País/jurisdicción.
- [ ] Formato: artículo, reel, video, guía o checklist.
- [ ] URL o archivo fuente.
- [ ] Miniatura autorizada.
- [ ] Fecha y duración cuando aplique.
- [ ] Texto en español e inglés.
- [ ] Responsable de validar vigencia tributaria.

Recurso inicial identificado:

- [ ] Reel de planeación tributaria: `https://www.instagram.com/reel/DWkVUxjkYXr/`.

## 6. Biblioteca de videos

Para cada video:

- [ ] Título, descripción y categoría.
- [ ] URL de Instagram, YouTube o proveedor de video.
- [ ] Miniatura horizontal.
- [ ] Duración.
- [ ] Fecha de publicación.
- [ ] País/jurisdicción.
- [ ] Transcripción o resumen accesible.
- [ ] Estado: borrador o aprobado.
- [ ] Autorización de imagen, música y material utilizado.

## 7. Aliados estratégicos

Para cada aliado:

- [ ] Nombre legal y nombre público.
- [ ] Categoría de la alianza.
- [ ] Países donde opera.
- [ ] Descripción breve de la colaboración.
- [ ] Sitio web oficial.
- [ ] Logo en SVG o PNG transparente.
- [ ] Autorización escrita para publicar nombre y logo.
- [ ] Persona responsable de aprobar el texto.

## 8. Testimonios

Recopilar al menos tres testimonios aprobados:

- [ ] Comentario textual.
- [ ] Nombre, iniciales o formato anónimo autorizado.
- [ ] Empresa e industria, si pueden publicarse.
- [ ] País.
- [ ] Servicio recibido.
- [ ] Fuente o enlace verificable, si existe.
- [ ] Permiso explícito de publicación.
- [ ] Confirmación de que no contiene datos financieros o tributarios privados.

## 9. Industrias y confianza

- [ ] Industrias prioritarias en orden comercial.
- [ ] Años de experiencia que pueden demostrarse.
- [ ] Certificaciones o asociaciones verificables.
- [ ] Herramientas utilizadas, si se pueden mencionar.
- [ ] Cifras o métricas autorizadas y su fuente.
- [ ] Fotografías profesionales, si se decide incorporarlas.

## 10. Legal, privacidad y medición

- [ ] Política de privacidad.
- [ ] Términos de uso.
- [ ] Aviso de contenido educativo.
- [ ] Consentimiento para formulario de contacto.
- [ ] Política de cookies si se usan tecnologías que lo requieran.
- [ ] Proveedor de analítica aprobado.
- [ ] Eventos de conversión aprobados.
- [ ] Responsable de responder formularios y mensajes.

## Aprobación final

- [ ] Todo el contenido está aprobado en español.
- [ ] Todo el contenido está aprobado en inglés.
- [ ] Los datos de contacto son consistentes en toda la landing.
- [ ] Los servicios están validados por país.
- [ ] Aliados y testimonios tienen autorización.
- [ ] Ningún contenido de muestra permanece visible en producción.
