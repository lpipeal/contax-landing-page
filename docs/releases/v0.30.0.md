# v0.30.0 · Primera aplicación basada en el prototipo consolidado

Esta entrega reemplaza la presentación anterior por la composición aprobada en `docs/prototypes/contax`: cabecera e ilustración, seis servicios, Estados Unidos y Colombia, planeación tributaria, tips, videos, diferenciadores, proceso, industrias, aliados/testimonios, contacto y pie de página.

El logo utilizado es el WebP transparente consolidado, con subtítulo blanco y la O corregida. El prototipo y los archivos originales de marca se conservan como referencia.

## Implementación

- [x] Componentes React y TypeScript; sin iframe ni inyección de HTML del prototipo.
- [x] Tokens de marca y estilos adaptables, ondas doradas y recursos locales.
- [x] Español e inglés con HTML y metadatos por ruta.
- [x] Servicios y recursos con diálogos; videos pendientes identificados como propuestas.
- [x] Formulario de consulta por país y servicio, con WhatsApp `+1 3463398946`.
- [x] ITIN restringido a Estados Unidos.
- [x] Menú móvil, navegación de teclado, Escape y devolución del foco.
- [x] Exportación estática y comprobación de enlaces y recursos antes de publicar.
- [x] Proyecto Firebase independiente `contax-business-solutions`.
- [x] Configuración Hosting, caché de assets con hash y 404 real.
- [x] Workflow GitHub Actions para validar ramas/PR/tags y publicar tags manualmente.
